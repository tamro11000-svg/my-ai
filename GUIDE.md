# My AI: your own free personal AI (runs in your phone's browser)

You upload 3 files to GitHub (free), turn on GitHub Pages (free), and open the address on your iPhone.
Your key, chats and files stay on your device only.

## 1. Free AI key
1. Safari: aistudio.google.com/apikey and sign in with Google.
2. Create API key. Copy it.

## 2. GitHub
1. github.com: sign up. Create a new repository named my-ai. Choose PUBLIC.
2. Tap "uploading an existing file". Upload these 3 files: index.html, manifest.json, icon.png. Commit changes.

## 3. Turn on GitHub Pages
1. Repository: Settings, then Pages.
2. Source: Deploy from a branch. Branch: main, folder: / (root). Save.
3. Wait 1 to 2 minutes. Your address is https://YOURNAME.github.io/my-ai/
   (No Settings button? In Safari tap aA, then Request Desktop Website.)

## 4. Install on your iPhone
1. Open the address in Safari. Share, then Add to Home Screen.
2. Always open it from the Home Screen icon. This protects your saved data.

## 5. Connect the brain
1. Open My AI. Go to Settings.
2. Provider: Google Gemini (free). Paste your key. Tap Find models, then Save and test. It should say Works.

## 6. Use it
- Chat normally. Files it makes are in the Files tab.
- Tell it to change itself: "add a tool that counts words", "make your colors green", "always answer in short sentences".
- Changes tab: see everything it changed and undo it.
- Changes to its core code ask for your approval first and roll back by themselves if they fail.
- Something broken? Add #safe to the end of the address.
- Settings, Make backup: do this now and then.

## Your team
You talk only to the leader. For bigger jobs the leader hands work to Nova (research), Quill (writing), Bolt (code and apps) and Sage (analysis and review). You see each staff member working in the chat (tap a card to open or close it). Their files appear in the Files tab.

Staff can improve themselves too. When they hit a gap or make a mistake they can save lessons into their own instructions, build new tools for the whole team, or propose a change to the app code (you must approve that one). Everything they change appears in the Changes tab, and you can undo it.
